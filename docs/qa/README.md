# Kiểm thử và nghiệm thu

**Cập nhật:** 26/10/2026

- `uat/` — biên bản UAT/nghiệm thu, tên `YYYY-MM-DD-<mã>-<môi-trường>.md`.
- Mỗi biên bản phải ghi: mã tính năng và phiên bản SPEC, **môi trường (mock hay API thật)** và commit, tài khoản/vai trò, từng AC → Đạt/Không đạt kèm bằng chứng, người kiểm và người xác nhận phía khách hàng (nếu có).
- Biên bản nội bộ không thay cho nghiệm thu của khách hàng; ghi rõ loại nào.

Các biên bản UAT 20/10/2026 trên demo mock đã chuyển vào [archive/2026-10/uat/](../archive/2026-10/uat/).
